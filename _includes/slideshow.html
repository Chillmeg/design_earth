{%- comment -%} The slideshow. Params: folder (image folder under assets/images), nav (true/false), box (optional height in px: a fixed frame, so the text below starts at the same place on every page; with box, the "1 of N Previous | Next" line is shown even for a single image, for the same reason). Markup matches the old Indexhibit slideshow; assets/js/slideshow.js builds the next slides. With box (PROJECT and EXHIBIT pages) every image is shown at one of two sizes, cropped to fill (CSS object-fit: cover, in slideshow.css): square and near-square (up to 1.25 wide for 1 high): 567 x 567 horizontal: 800 x 533 (3:2) Vertical images (narrower than 0.95 wide for 1 high) are left out of the slideshow. Panoramas (1.9 wide for 1 high or wider, e.g. Julia's strip) get the same 800 x 533 frame but are shown whole, at the top of the frame, since cropping them would leave only a small slice. An image with `scroll: true` (Julia's strip) is shown at its own width/height from the front matter, inside an 800px-wide box that scrolls sideways. With fit_height (PUBLISH pages) every image is scaled to that height instead, width following the image: nothing is cropped or left out. {%- endcomment -%} {%- assign base = "/assets/images/" | append: include.folder | append: "/" -%} {%- assign shown = 0 -%} {%- assign first = nil -%} {%- capture slides_js -%} {%- for im in page.images -%} {%- assign w = im.width | default: 0 -%}{%- assign h = im.height | default: 0 -%}{%- assign pano = false -%} {%- if im.scroll -%} {%- elsif include.fit_height and w > 0 and h > 0 -%} {%- assign w = w | times: include.fit_height | divided_by: h -%}{%- assign h = include.fit_height -%} {%- elsif include.box and w > 0 and h > 0 -%} {%- assign r = w | times: 100 | divided_by: h -%} {%- if r < 95 -%}{%- continue -%}{%- endif -%} {%- if r >= 190 -%}{%- assign pano = true -%}{%- endif -%} {%- if r < 125 -%}{%- assign w = 567 -%}{%- assign h = 567 -%}{%- else -%}{%- assign w = 800 -%}{%- assign h = 533 -%}{%- endif -%} {%- endif -%} {%- if shown == 0 -%}{%- assign first = im -%}{%- assign first_w = w -%}{%- assign first_h = h -%}{%- assign first_pano = pano -%}{%- else -%}, {% endif -%} {%- assign shown = shown | plus: 1 -%} { src: {{ base | append: im.file | relative_url | jsonify }}, width: {{ w }}, height: {{ h }}, caption: {{ im.caption | default: "" | jsonify }}{% if pano %}, pano: true{% endif %}{% if im.scroll %}, scroll: true{% endif %} } {%- endfor -%} {%- endcapture -%} {% if include.nav and shown > 0 %}{% if shown > 1 or include.box %}
